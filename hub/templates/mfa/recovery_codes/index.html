The stock page (65.22) shows the codes and an "I have saved my recovery codes" tick box, and nothing else: no button, so a person who has just set up two-step sign-in is left with nowhere to go. This one adds the way on. Recovery codes are shown once (MFA_RECOVERY_CODES_SHOW_ONCE). allauth marks them as seen while it draws this page, so its own download address refuses from then on. "Download" here is therefore a link that carries the codes itself (a data: address), and needs no second request. Without JavaScript the page still works: the tick box is `required`, so the browser will not follow "Continue" until it is ticked.
